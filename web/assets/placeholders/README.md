# 美术资源预留

入口：`/art-preview.html`，可查看 Loading、主菜单、三关地图和新增 UI 资源目录。

`ui-reservations.json` 与 Excel 新增编号 A-087 至 A-131 顺序对应。字段依次为分类、资源名、数量/变体、位置、建议尺寸、格式、状态、替换槽位、说明。

- 主菜单“开始游戏”打开三关地图样稿；关卡入口只说明预留状态，不进入正式战斗。
- Loading 为静态进度样式，65% 是示意值，不表示网络加载进度。
- 页面中 `data-slot` 与清单“替换槽位名”对应。正式素材可据此替换当前 CSS/SVG 占位。尚无正式插画或切图文件。
- 地图区域暂名关中、中原、江淮，仅表达战国题材局部地图的西、中央、东南构图。区域边界不是历史国界，具体时代和疆界 TBD。
- 关卡1/2/3与现有对局内的两波敌军不是同一概念；敌阵、解锁、奖励、战斗接入 TBD。
- 横版基准1920×1080；手机资源参考1344×2772，布局参考448×924。底图需横竖两种构图，区域遮罩、描边和节点与底图使用一致坐标。
- 字体、题字和最终地图应另行确认授权；本页为代码绘制示意，不使用参考图的像素或矢量路径。
