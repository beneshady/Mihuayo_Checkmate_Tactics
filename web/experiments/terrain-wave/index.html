    实验范围与操作说明

    击杀敌将即通过本波，我方帅阵亡则失败。保留九宫、炮架、马腿和敌方先准备后预告的规则。兵及转职兵从任何位置都可向前、向左、向右移动，不能后退。

    为了不依赖成长即可测试：我方车预设冲击 3 格与震退；弓、枪四向射程预设 3 格。炮不预设扩散。其余初始属性与当前六人阵容一致。这些是实验预设，不是正式平衡结论。

    敌方会避开致死水路，无安全进展时待机；实验暂不主动选择山为攻击目标。车拆山后停在前一格。主动致死移动需确认，执行后不可撤销。攻击（包括 miss、冲击入水中断）均锁定此前移动。

    水与山的占位规则对双方一致。树林闪避同时取消伤害和击退；预测显示可能结果，不提前判定闪避。第二波将换地形，但不在本次单波实验内。无商店、升级、存档或主原型改动。

    专项练习仅便于验证交互，不代替单波通关。山林布点、敌人是否主动拆山，以及自亡撤销规则均仍属实验选择，待试玩确认。地图编辑允许修改任意格地形和双方棋子，但开始测试前须满足九宫、占位和双方将帅存在等约束；敌方最多八枚，马可通过编辑器加入调试。
