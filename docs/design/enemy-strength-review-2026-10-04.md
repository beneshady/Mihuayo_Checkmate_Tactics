## 2. 主要结论

| 观察 | 证据等级 | 判断 |
| --- | --- | --- |
| 默认开局有三条兵的近身威胁，左侧普通兵还面对炮击；无干预时第一回合该兵承受潜在合计3伤害 | 规则/意图诊断 | 开场同时要求玩家理解兵、炮架和弓盲区，新手教学压力可能偏高，待真人验证 |

## 3. 可重放样本与限制

执行：`node docs/us/us010-balance-probe.cjs`。

脚本从 `newGame` 开始，经过正常布阵确认、三选一、合法动作和回合结算。无金币/SP/HP/阶段注入，不升级、不改阵容。三种 buff 各跑4种策略，共12个确定性样本；不是随机样本，也不是独立玩家样本。

- `wait`：不行动。
- `greedy-attack`：只看当前局面的简单贪心选择，不前瞻敌方结算。
- `greedy-safe`：用下一次敌方结算后的存活/血量/击杀评价选择动作。
- `king-only`：同样前瞻，但只允许操作主帅；救援 buff 样本仍按规则处理换波救援，不是完全零交互。
- 贪心只取严格改善评价的单步行动，可能遗漏“先暂时不获益，再完成组合”的解法；三种 buff 结果也不能据此直接排名。

| 策略 | 坚守 | 疾行 | 救援 |
| --- | --- | --- | --- |
| 不行动 | 第6回合失败，0金币 | 同左 | 同左 |
| 当前收益优先 | 第6回合失败，4击杀但0金币 | 同左 | 同左 |
| 考虑敌方结算 | 第11回合成功，7击杀/7金币，帅1HP | 第11回合成功，8击杀/8金币，帅3HP | 第11回合成功，8击杀/8金币，帅3HP |
| 只移动主帅 | 第11回合成功，0击杀/0金币，帅3HP | 同左 | 同左 |

### 3.1 实机零击杀路线

正常入口、默认部署、选择疾行。第1～3回合不行动；第4～11回合仅移动主帅，依次落在：

`(3,0) → (3,1) → (4,1) → (3,2) → (4,2) → (4,1) → (3,0) → (4,1)`。

每回合均通过“结束回合→确认，执行敌方意图”结算。第5回合实际可见6个增援格标记，第6回合出现第二波；不是只跑第一波。第11回合结算后进入关间整备，金币0，购买按钮禁用，但可以开始下一关布阵。重新选疾行后，我方帅车炮兵弓枪全部满血出现。

证据：[零金币关间整备](../us/us010-balance-king-only.jpg)、[下关队伍满血返回](../us/us010-balance-next-level.jpg)。此路线**没有验证购买闭环**，不能替代 US-010 AC21–26 的真实赚币购买验收。

### 3.2 开场无伤解法（规则诊断及实机复现）

1. 普通兵 `(1,3)` 攻击 `(1,4)`，杀敌但不占位。
2. 炮 `(1,2)` 移动到 `(4,2)`。
3. 炮利用弓 `(4,3)` 为炮架，攻击 `(4,4)` 的敌兵。
4. 枪兵 `(7,3)` 向前攻击 `(7,4)`。
5. 结束回合：进入第2回合，3击杀，全部6枚我方单位满血。

这也解释了“单步贪心结果差”不代表开局无法保护全队：移动炮本身没有立即造成伤害，却为下一动作创造炮架。

实机在零击杀通关后的下一验证关，默认部署、再次选择疾行，逐步执行上述动作。第2回合六枚我方均满血、击杀3、金币仍0（关末才结算），炮重新获得移动/攻击额度；没有购买、升级或注入资源。[实机截图](../us/us010-balance-opening.jpg)。

## 4. 数值、经济与成长检查

| 项目 | 当前数值/关系 | 解释与边界 |
| --- | --- | --- |
| 敌方兵/士/马 | 1HP / 1攻击 | 我方1伤害可一击杀；士受九宫限制，数量不等于全场持续威胁 |
| 敌车 | 2HP / 1攻击 | 对1伤害需2次命中；炮/弓2伤害可一击杀 |
| 敌炮 | 2HP / 2攻击 | 对1～2HP队友具有一击击杀威胁，但必须满足炮架条件 |
| 敌将 | 5HP / 1攻击 | 单个1伤害来源需5次命中，2伤害来源需3次；不是必定5或3回合，因为可多人攻击 |
| 波次总量 | 首波8敌/14HP，次波6敌/8HP | 全关最多14敌/22HP；未入场者不能算当前压力 |
| 理论杀敌金币 | 普通13×1 + 将5 = 18 | 上限，不是平均收益；提前斩首会取消未来增援，未出现单位不给钱 |
| 商品价格 | 兵3，基础车/马/炮5 | 诊断成功样本7～8金币可承担一个5金币队友；能承担不等于两条购买流程已验收 |
| 失败 | 当关收益不到账、恢复入关快照 | 无失败刷本关收益的设计许可；实现仍需完整失败快照回归 |
| 牵引车存活奖励 | 成功且上阵存活+1SP | “避战过关+被动成长”可能进一步降低交战动机；尚未做正式养成对局验证，标记待测 |

关卡难度随关数、队伍成长后的压力、招募后阵容最优解：当前缺独立关卡内容及足量样本，**不作通过结论**。

## 5. 建议，均待用户决策

1. **本轮不调敌将5HP，也不整体加攻击。** 先完成既定功能验收，避免用数值变化掩盖规则/交互缺陷。
2. 若目标是要求玩家利用队友解题，优先评估敌人预告的空间协同：能否同时压缩主帅的安全落点，而不是单纯提高每次命中的伤害。仍须保持意图冻结、可预览，不临时追踪逃离目标。
3. 先明确“零击杀生存是否是认可的低收益打法”。若认可，就通过金币/关卡目标呈现其代价；若不认可，需要用户批准目标或关卡设计调整，不能验收时偷加击杀门槛或永久死亡。
4. 首关可优先提供炮架联动、弓相邻盲区的提示；这是可理解性建议，不代表已批准新 UI 开发。
5. 后续用至少三类人工试玩记录区分：不了解规则导致的失败、理解预告后的合理损失、重复避战。当前不设虚构目标胜率。
