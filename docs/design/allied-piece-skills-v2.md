## 2. 设计目标与通用底线

### 2.1 希望形成的体验

玩家看见一次确定的威胁后，应有不同解法：直接杀死攻击者、改变其位置、换出受击队友、冻结一次攻击，或用主帅增益承担伤害。技能的价值应来自不同解局方式，而不只是更高攻击力。

这是设计目标，尚无本方案完整试玩证据。兵炮输出、车马控位、士守家、象施法、主帅增益的分工需要在同一局面中比较验证。

### 2.2 通用规则（含本轮确认的替换项）

- 棋盘为 **9×9**，坐标 `x,y=0..8`；我方底线为 `y=0`，河道为 `y=4`，敌方半场为 `y=5..8`。
- 我方九宫为 `x=3..5,y=0..2`，敌方九宫为 `x=3..5,y=6..8`。主帅在本宫内按横竖一步及米字线移动，不引入飞将。
- 每格最多一个占位对象：存活棋子、装置或尸体。死亡与尸体处理改按第2.3节，不再沿用“所有阵亡单位直接移除”。
- 敌方先准备移动，再冻结攻击意图；我方行动后，敌方按稳定顺序结算。敌人被推动后保持原攻击方向与相对距离，落点随位置平移，不追踪原目标单位。
- 只有车通过攻击击杀时占据目标原格。马的撤离或交换位置属于单独位移，不是击杀占位。
- 主帅实际阵亡才失败，不提前以“将死搜索”判负；同次结算双方主帅阵亡时己方失败优先。
- 非法操作不消耗行动或资源。预览不改变真实状态；实际执行须与预览采用相同判定。
- 不增加随机暴击、命中率或随机技能目标。独立地形实验的规则不会自动合入本文。

### 2.3 尸体与入水【用户确认】

- 我方队友棋子（含转职单位）死亡后在原格留下尸体；敌方死亡直接消失，不留尸体。主帅死亡仍立即失败，不能救援；仕属于装置，摧毁直接移除，不留残骸。
- 尸体占格、阻挡移动及马腿，可作为炮架，也可被推动；同关换波保留当前位置。它不是存活目标，不能因为可作炮架就自动成为所有伤害技能的合法目标。
- 陆地上的尸体不能被伤害摧毁，不设置HP；**入水销毁及V2.3敌人出生清尸是明确例外**。河道为`y=4`；US-009新增`(1,4)/(4,4)/(7,4)`永久桥梁，按陆地处理且不可摧毁；其余6格为水面。尸体进入水面销毁，不再占格、阻挡或充当炮架，桥上尸体保留。
- 象生前可停河道，死亡后失去漂浮能力：象在水面死亡直接消失；象的陆地尸体进入水面同样销毁。其他我方棋子在水面死亡也不留尸；在桥上死亡则按陆地留尸。
- 入水销毁替代此前讨论的“用生前区域限制阻止尸体入河”。**【多格位移边界建议 / TBD】** 推动按经过的格子判定入水，经过河道就销毁，不通过只检查终点跳过河道；多格推拉与瞬间交换尚未定案，不能把该建议标为已确认技能。
- 尸体尚在时，救援在其**当前位置**复活原单位；尸体销毁后，该单位本关不可再救援。下一关仍按第9.4节满血回归，不属于永久失去队友。
- 弓兵箭路被尸体阻挡，包括相邻1格盲区，具体按US-009。V2.3新增确认：枪兵遇尸体截断，前方敌人正常命中；解锁震退的冲锋车可消耗冲锋机会推尸，牵引车可拉尸，详见补编第2/7节。这些是新合同，不等于现有代码已支持。

当前原型转职花2 SP，定向强化与强健各1 SP，连动2 SP；这些是实现现状，不是对新成长系统再次确认价格。转职只赠送一次，保留同一单位身份和已有成长。

### 4.2 炮【沿用】

- 初始生命2、基础伤害2、普通直线移动最多3格；我方可一次移动后再一次攻击。
- 炮与主目标同一直线，中间恰好一个炮架，不另设主目标数值射程上限；存活单位阵营不限。本轮增加我方尸体可作炮架，不能把尸体本身当作存活攻击目标。
- 初始只命中一个主目标格，不用先升级才有攻击。
- 每次扩散强化选择主目标八邻格中的一个未开启格，包含斜邻格，最多8次；方向相对棋盘固定，不随射击旋转。
- 各覆盖格内单位均受2伤害，可误伤友军及炮架。先确定命中范围，再同时结算；炮架本次被炸死不撤销已经发出的炮击。
- 当前原型扩散每格1 SP。新成长设计改为升级时选择的部分不由本文自动实施。

## 5. 车：基础车与两个转职【V2.3用户确认】

完整合同以[补编第7节](gameplay-v2.3-confirmed.md#7-车的职业树)为准，旧“初始即冲锋车/移动3格/受阻无碰撞/牵引纯候选”作废。

- 基础车2血1攻、直线行动4格，移动攻击合一，不能先移再攻；杀敌占位，未杀停前，不自动推人。
- 花2SP不可逆转为冲锋车或牵引车，不互转、不退回、不实施未获批准的退款方案。
- 冲锋车普通移动4、独立冲锋1，可换方向；冲锋每1SP+1至8；震退1SP解锁推1格，可推尸并产生已确认碰撞。
- 牵引车可移后拉：首个同线友军/敌军/尸体拉近1；射程3，每1SP+1至8。正常拉动无直接伤害，贴身敌人可强拉双方各受1碰撞；友军/尸体无合法落点仍禁用。
- 牵引碰撞击杀归牵引车；成功过关时上阵且存活另获1SP，不给后备、不按波次重复。
- 主帅移动buff只加普通移动；基础车纯移可5但攻击仍4，冲锋/牵引射程不变。基础车付费距离升级联动与拉2格候选仍未确认。

## 6. 马：两个转职方向

普通马沿用日字走法和蹩马腿；初始生命1、伤害1，普通移动和攻击共用一次基础行动。两路线建议互斥且本局不能反复互转，转职条件 TBD。

### 6.1 突骑【候选 / TBD】

- 保留日字攻击，攻击在原位置结算。成功攻击后获得一次额外日字撤离机会，只能移动到合法空格，不能再次攻击。
- 撤离从马当前格计算，不从敌人所在格计算；可放弃，没有合法落点也不会撤销之前的攻击。
- 撤离初始受马腿限制；“轻身”升级可只解除撤离时的马腿限制，不同时改变普通移动和攻击。
- 其他升级候选：攻击伤害+1，建议只升一次；强健。
- 成长不补充攻击或撤离机会；额外撤离当回合不用即失效，不能跨回合积累。
- 先杀敌后撤离属于一个战术动作链；若攻击已结束战斗，不再要求选择撤离。

用途：击杀后撤出预告落点，或者腾出炮路。风险：撤离范围过大时，可能使危险站位失去代价。

### 6.2 护骑【候选 / TBD】

- 保留普通攻击；新增救援，与日字范围内一枚存活友军交换位置，替代本次攻击 / 共用行动。
- 双方作为一次原子换位同时落位，不经过中间占格，不制造短暂的重叠单位。
- 基础救援从马的位置判断日字与马腿。升级候选“越障救援”解除救援的马腿限制，不解除双方最终落点限制。
- 交换不恢复双方已经消耗的行动次数，不治疗、不加伤、不提供护盾。被救单位仍用自己的剩余行动。
- 主帅只有交换后仍在本宫内才合法；固定士不能被交换；象不能被换进敌方半场。
- 另一条升级保留强健。更多救援强化、每回合使用上限是否增加 TBD，初版不默认增加。

**方案修订说明：此前“救援后赠送护盾”的升级不纳入本稿有效候选。** 用户随后把给队友加 buff 的职责交给主帅，护骑因此专注位置交换，避免把旧建议混入最新方案。

## 7. 士：固定哨卫

### 7.1 用户确定的规则

我方仕（旧稿写作“士”）属于固定装置，不是可操控棋子；固定在己方九宫左右两个角，敌方单位进入射程时自动攻击，类似炮塔。下文我方“士”均指该装置；敌方士仍是棋子，继续沿用已有九宫内移动规则。

- 三种主帅buff全部排除仕：不加血量上限、不加移动，不能补血或救援复活。
- 仕被摧毁直接移除，不留尸体或残骸，不占格、不能再作炮架或被推动。
- 同一关换波：存活仕保留位置和剩余血量，已摧毁仕不重建。
- 下一关：按新关卡规定的位置重新配置满血仕，包括上一关被摧毁的仕。这是关卡初始化，不是治疗或复活技能。

### 7.2 初版候选规则【候选 / TBD】

| 参数 | 建议初值 | 说明 |
| --- | --- | --- |
| 位置 | 靠河一侧两个角 `(3,2)`、`(5,2)` | 前角还是底角尚未确认；是否开局两枚都自带也待确认 |
| 基础生命 | TBD | 不直接套用敌方士生命作为已确认数值 |
| 警戒范围 | 前后左右各2格 | 不包括斜向；被存活单位挡住，不能越过友军打后面的敌人；尸体是否截断射线仍TBD |
| 伤害 | 1 | 单目标确定伤害，不溅射 |
| 基础次数 | 每枚士每轮最多1次 | 非实时计时攻击，不因反复进出范围无限开火 |
| 可移动性 | 完全固定 | 建议同时拒绝推、拉、交换；阵亡后正常移除 |

升级候选：选择一个方向延长1格；解锁每轮第二次警戒攻击；伤害+1且建议限一次。价格、各方向射程上限、可用升级入口 TBD。

### 7.3 自动攻击结算建议【候选 / TBD】

为补齐自动触发的顺序，提出以下可测规则，尚未获确认：

1. 每次敌方准备阶段开始时刷新士的警戒次数；从该阶段起到紧接着的敌方攻击阶段结束为一个警戒周期，中途不重复刷新。
2. 刷新时已有敌人在警戒范围内，或一个完整移动 / 强制位移动作结束后敌人处于可射击范围，均检查是否可触发。该补充避免敌人停在射程内反而永远安全。
3. 同时有多个目标时，建议按“距离最近→敌方稳定行动序号”选取；两枚士同时可触发则先左后右，后者依据前者结算后的局面重新检查。
4. 士的射击完整结束后才继续下一步。敌方准备期间被击杀的敌人不再生成意图；玩家阶段被射杀的攻击者从有效威胁中移除，不重选其他敌人的意图。
5. 拉动或交换的落位先完整完成，再结算警戒；初版不按动画经过的每个像素或中间格触发。
6. 可选动作的预览必须包含随后自动触发的士攻击、死亡与炮架变化。

以上会使“敌方准备阶段原本不造成伤害”出现我方警戒反应例外，正式采用前必须修订回合合同，不能当成对旧实现的小修复。

## 8. 象：法师职业

### 8.1 定位与行动

**【用户确认】** 象改为法师，不再承担给友军加 buff 的职责；可停在河道，不能进入敌方半场。此前“护阵象 / 战鼓象”候选废止，不并存。

**【用户确认】** 基础只可沿四个斜方向移动2格（田字），不开放斜走1格。移动buff生效后可选择斜走2格或3格；不是增加一次行动，也不增加法术射程。斜走2格检查中间1格，斜走3格检查中间2格，路径和落点均不能被棋子、装置或尸体占据；不能中途转向。

**【候选 / TBD】** 允许先移动一次，再施法一次；施法后关闭剩余移动。雷击与冰封共用一次施法机会，不是两种技能各放一次。暂不引入法力资源、普通近战攻击或两种法术职业分支。

存活象仍占格，可充当炮架及阻挡。建议主动移动、推拉、救援交换均不能使存活象进入 `y>=5`；河道 `y=4` 合法。“漂浮”不代表与其他棋子重叠或跨越单位；象的尸体不再漂浮，入水即销毁。初始生命、出生 / 购买入口以及双技能是否初始全部解锁 TBD。

### 8.2 技能一：雷击【候选 / TBD】

| 项目 | 初版方案 |
| --- | --- |
| 定位 | 短程、稳定的单目标法术输出 |
| 目标 | 一枚存活敌方单位，不选友军或空格 |
| 射程 | 3格，横向距离与纵向距离之和不大于3 |
| 伤害 | 2，固定伤害，不连锁、不扩散 |
| 遮挡 | 不需要炮架，中间棋子不阻挡；不据此推定未来山地也不阻挡 |
| 位移 | 象与目标均不因雷击移动；击杀也不占位 |
| 使用频率 | 每回合最多占用一次共用施法，无额外冷却 |
| 成长归属 | 实际击杀按最终采用的成长系统记给象，不记给提供炮架或控场的队友 |

例：象在 `(4,4)`，敌人在 `(5,6)`，距离为3，可雷击；敌人在 `(5,7)`，距离为4，不能施法。射程内有其他棋子不会挡住雷击。

与炮的区别：炮依赖同线炮架、可远射和扩散；雷击射程较短、无炮架要求、只能打单体。不直接照搬炮的范围升级。

### 8.3 技能二：冰封【候选 / TBD】

| 项目 | 初版方案 |
| --- | --- |
| 定位 | 暂停一次危险攻击，换取处理时间 |
| 目标与射程 | 一枚存活敌人，距离算法同雷击，射程3格；建议同样不被棋子遮挡 |
| 伤害 | 0，不因施法本身授予击杀成长 |
| 效果 | 跳过紧接着的敌方攻击阶段中该单位的一次冻结攻击，之后解除 |
| 意图 | 保留原预告，标记“冰封，本次不执行”；不重新生成目标，不转向 |
| 冷却 | 第N个玩家回合施放后，第N+1回合禁用，第N+2回合恢复；冷却期间雷击仍可用 |
| 占位 | 仍占格、挡路、蹩马腿、可作炮架，也能受到推拉与伤害 |

补充边界建议：

- 状态绑定被冰封单位，不绑定地面格。被推拉后，预告仍按相对方向平移，但此次攻击继续跳过。
- 冰封不是“取消一切动作”：它不回滚已经完成的准备移动，也不禁止之后受到其他单位推动。
- 跳过后的攻击不会延期补发；下个准备阶段再按正常规则产生新意图。
- 目标若本来待机或意图因炮架变化失效，冰封仍在最近一次敌方攻击阶段结束前清除，不保留到遥远未来。
- 目标提前死亡，状态随单位移除，但不返还已消耗的施法机会或冷却。
- 已冰封目标建议禁止重复施放；不叠层、不延长持续时间。
- 是否可作用敌将、多个象轮流冰封同一单位、跨波是否清冷却均为高影响 TBD，不能默认为永久控制首领。

例：3 HP 敌车即将威胁主帅，雷击只能削到1 HP，仍可能攻击；冰封能保住这一轮，但没有削血，也没有获得击杀成长。此例仅说明决策差异，不代表所有局面都应优先冰封。

### 8.4 象的升级候选

用户目前只要求设计两个技能，未确认象的成长树。可供下一轮讨论的最小候选为：强健；雷击施法距离+1；冰封施法距离+1，两种射程分别强化。升级上限、门槛 TBD，暂不提出冰封群体化、冷却归零或无限叠加伤害。

## 9. 成长与主帅增益

### 9.1 棋子成长与主帅增益是两套规则

- 【V2.3确认】本批保留个人技能点成长与付费转职/升级，不实施旧稿取消SP的迁移，也不同时免费发一次技能选择。
- 【V2.3确认】碰撞击杀归主动发动技能者，发动者同时死亡不获成长；牵引车成功过关且上阵存活另获1SP，后备不获。这不是每波赠点或按操作刷点。
- 【TBD】护骑救援收益、仕自动击杀成长等未定职业边界仍不实施；其余细节见V2.3补编。

### 9.2 主帅增益：本轮确认的简化方向

**【用户确认】每关开始三选一：友方血量+1、友方移动距离+1、波间救援。效果同关跨波保留；下一关重新选择并替换旧buff，不累积、不叠层。三项都排除主帅本人及仕装置，本关新购买的队友继承当前有效buff。**

本修订优先采用上述简单入口。此前“胜利后用金币解锁主帅buff”的方案暂缓，不作为本版选择的前置门槛；金币购买、永久解锁和装配槽都不在当前简化范围。是否未来恢复经济解锁需另行确认，不改动已有队友商店。

### 9.3 三选一选项

| 选项 | 效果 | 确认状态 | 解释与限制 |
| --- | --- | --- | --- |
| 坚守 | 友方最大血量+1 | 用户确认 | 关卡初始化按调整后的上限满血；同关换波只保留上限，不重复加血，不自动回满 |
| 疾行 | 友方普通移动距离+1 | 用户确认 | 不增加攻击、冲击、施法距离或行动次数；具体适配见下表 |
| 救援 | 每次换波时指定一名我方棋子：存活则回满血，死亡且尸体尚在则复活为1HP | 用户确认 | 排除主帅和仕；一次换波共一个目标，并非全队恢复或每人一次 |

此前“强攻 / 攻击+1”候选已被用户否决，由救援替代，不再作为有效第三选项。三项名称是文案，不影响已确认效果。

**覆盖对象【用户确认】：** 我方棋子，但排除主帅、仕装置。新购买队友加入本关后同样享受所选效果，救援仍只有每次换波一次的额度，不因购买赠送额外次数。血量buff本身不复活死者；相同buff不得因转职、恢复页面或换波重复授予。

**移动适配：** 在棋子已有普通移动能力上加距离，不是多一次行动；马的方案为讨论暂定，须验证UI可理解性。

| 棋种 | 规则与状态 |
| --- | --- |
| 车、炮 | V2.3车初始普通移动4→5，基础车攻击仍4；冲锋/牵引射程不变。炮普通移动仍3→4。不越棋子、装置或尸体【确认】 |
| 普通兵、弓兵、枪兵 | 普通移动最多2格，也可走1格；合法方向按起点是否过河判定，途中不转向、不穿子或尸体；攻击距离不变【确认】 |
| 帅 | 不享受buff，原九宫走法不变【确认】 |
| 马、突骑、护骑 | 一次普通移动可先完成合法日字，再可选沿前后左右延伸1格；原日字蹩马腿保留，中间日字落点及最终延伸格为空；可只走原日字。不增加攻击、突骑撤离或护骑换位距离【暂定，UI与试玩TBD】 |
| 仕 | 装置，排除；固定不动【确认】 |
| 象 | 基础斜走2格；buff下可选斜走2或3格，不开放1格；整条路径及落点空，不转向、不越河，不增加法术范围【确认】 |

移动卡片明确标注“我方棋子，主帅与仕除外”。马的扩展必须一次点击最终落点即可完成，预览展示完整路线，不能要求玩家走完日字后再寻找隐藏的第二步按钮；用户已指出其交互可能与其他棋子不统一，不以方案写入文档视为体验通过。

**救援的目标与时序【用户确认】：**

- 上一波结束后、下一波敌人入场及生成意图前，选择一个目标并结算救援；不是在敌人行动后补救。
- 存活目标当前HP恢复到其最大HP。死亡目标须有仍存在的尸体，移除尸体并在该格恢复原单位，当前HP为1；保留原职业、等级、已获技能和最大HP。
- 尸体被推过，复活点随尸体当前位置变化，不回出生点或最初死亡位置。入水销毁的尸体不可选择。
- 主帅死亡直接失败；仕不能补血、不能复活。二者均不可成为救援目标。
- 初次开关不赠送一次波间救援；关卡最后一波结束后没有下一波，不额外创建恢复阶段。无合法目标时跳过的UI及玩家主动放弃入口为低风险实现建议，尚未作为用户确认规则。

### 9.4 波次、关卡与整轮闯关（历史口径，以下冲突项由V2.3替代）

**最新执行口径：** [V2.3第4～6节](gameplay-v2.3-confirmed.md)确认固定两波，第5回合预告、第6回合救援后增援，旧敌不清场；第11回合结束存活或提前杀将均过关。金币关末结算、关间商店、当前关快照重试、8队友+帅、无限后备与手动布阵已获批准。下方旧“上一波结束→下一波”和“出生冲突TBD”不再是本批合同；跨关满血、buff替换等未冲突条款继续沿用。

为避免混用名词，已确认以下口径（关卡地图仍为预留）：

- **波次**：同一关内的敌人批次。切换波次保留已选主帅buff，**不触发新的三选一**，也不重复发同一份属性加成。
- **关卡**：未来地图上的一个战斗节点，可包含多个波次。进入下一关时，再提供一次三选一，新buff替换旧buff。
- **整轮闯关**：从新游戏开始到最终通关 / 失败结束。当前两波原型可先视作一关，用于验证跨波保留；这是适配建议，不宣称地图已经存在。

**【用户确认】开关流程：** 展示本关地图和初始敌方配置 → 玩家三选一 → buff生效并完成初始化 → 敌方先准备行动并锁定攻击意图 → 玩家行动。

玩家能根据地图、阵容选择buff，但首次敌方意图在选择生效后才生成。选择完成前不推进战斗，不能在战斗中随意改选。

**【用户确认】同关换波：** 上一波结束 → 保留我方存活棋子、仕及尸体的位置和剩余HP，不重部署、不自动治疗 → 若选救援则处理一个目标 → 下一波敌人入场并准备、生成意图。仍使用原buff，不重新选择、不叠加同一份属性。

**【用户确认】跨关初始化：** 清除旧主帅buff → 本关三选一确定新buff → 按新buff后的最大HP恢复所有我方队友，包括上一关死亡或尸体销毁的队友 → 在新关卡规定位置配置。仕按装置规则重新满血配置，主帅不享受buff。上一关尸体不带进新关卡；不叠加历关buff。

由于换关会满血恢复，不需要保留旧关的残血或靠裁切当前HP处理旧血量buff的撤销。新开整轮不继承上一轮主帅选择；本稿不引入跨局永久buff。下一波出生点与存活单位、尸体冲突时不能重叠生成，具体出生配置与避让方案留给关卡设计确认。

### 9.5 最小范围与未来接口

本阶段设计包括简单选择面板、有效buff显示、同关跨波保留、新队友继承、波间单目标救援及其尸体依赖。不设计地图节点类型、路线生成、随机事件、永久解锁树或金币价格；并非只改一张选择面板即可宣告完成。

只在规则文档中预留“新关卡开始”的选择节点；未来地图可从该节点接入。不为尚未实施的地图预建复杂框架。

## 10. 交互、表现与边界

### 10.1 必须看得懂的反馈

- 延续整格覆盖预览，不用小圆圈代替实际命中范围；区分移动、伤害、强制位移、冰封与士的警戒范围。
- 牵引显示原位置、路径与最终位置；护骑同时显示双方终点及是否合法；突骑明确区分攻击确认和可选撤离。
- 象选中后显示雷击 / 冰封两个按钮、射程、伤害或控制效果、共用施法额度，以及冰封最早可用回合。
- 冰封后不能把敌方预告直接藏掉：保留方向和落点，用图标与文字标明本次跳过，不能只靠颜色。
- 士显示本轮剩余警戒次数、实际阻挡后的射程、自动选中的目标和先后顺序；玩家预览推拉时立即显示连带射击结果。
- 主帅选择卡注明“排除主帅和仕”，选后显示“本关跨波有效，下关替换”。救援区分“回满血 / 原尸体位置复活为1HP”，无尸体单位不可选；入水预览显示尸体销毁、本关无法救援。本版不增加金币购买界面。
- 原型允许简单符号、短闪光和文字；本稿不要求正式美术、音频资产或新工具链。动画不能决定伤害次数，切页暂停也不能消耗回合冷却。

### 10.2 跨系统边界

| 情况 | 规则 / 状态 |
| --- | --- |
| 推拉敌人 | 沿用冻结方向与相对距离，不重新追踪目标 |
| 固定士受到位移技能 | 候选：拒绝；具体固定性质确认前不得实现可搬运炮塔 |
| 换位一方落点出宫 / 象跨河 | 候选：整次交换失败，不只移动其中一方 |
| 冰封后再推动攻击者 | 候选：状态随人，落点平移，最近攻击仍跳过 |

| 带警戒伤害的移动被撤销 | TBD；不能仅还原移动而保留击杀收益。建议造成任何伤害或成长后锁定该动作的撤销 |
| 多个象控制同一个首领 | TBD；需明确首领免疫或再冻结限制，不能宣称现有冷却已杜绝永久控制 |
| 水、山、树林 | 本轮仅确认河道尸体入水销毁；其他地形草案仍未自动采用，不把“棋子不挡法术”扩成所有地形无效 |
| 关卡结束与下一次三选一 | 下一关开始再次选择并替换旧buff；所有队友满血返回，仕重新配置。同关换波原位、保留剩余血量及尸体，不多给一次选择 |
| 尸体损伤与入水 | 普通伤害不能销毁尸体；入水立即销毁，包括象的尸体；此后本关不可救援，下一关队友仍回归 |

## 11. 距离、参数与可调项

法术距离定义为：`d = abs(tx - sx) + abs(ty - sy)`；合法目标需 `1 <= d <= R` 且为允许的存活单位。

| 变量 | 类型 | 范围 | 来源 | 含义 |
| --- | --- | --- | --- | --- |
| sx, sy, tx, ty | 整数 | 0..8 | 棋盘状态 | 施法者与目标坐标 |
| d | 整数 | 0..16 | 上式计算 | 曼哈顿距离；不是切比雪夫距离，不允许“横3且竖3”也算3格 |
| R | 整数 | 初版建议3；升级上限TBD | 本稿候选参数 | 对应法术射程 |
| N | 整数 | 不小于1 | 回合状态 | 本次冰封施放的玩家回合序号 |
| nextReady | 整数 | N+2 | 候选冷却规则 | 同一波内冰封最早恢复回合；跨波重置另行确认 |

法术基础距离3与伤害2、牵引距离3 / 拉动1、士警戒距离2 / 伤害1 / 次数1，都是试玩起点，不是已验证平衡结论。初版优先比较能力差异，避免同时提高范围、伤害、频率导致无法判断收益来源。
