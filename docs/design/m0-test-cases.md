# 2.5D 象棋 M0 测试用例

版本：v0.2｜日期：2026-09-06

依据：[M0 初始 GDD](m0-gdd.md)
状态：分项执行中；用例定义不代表已经通过，本次实际结果见第 7 节。

## 1. 使用说明

- 测试范围是 M0 的纯规则、完整流程、Cocos 表现和本地微信包验证。真机三人验收须在实际设备上另行记录机型、系统、包版本、执行人和结果。
- `R` 为纯规则自动化测试；`I` 为场景/交互集成测试；`P` 为试玩或平台测试。优先级 `P0` 阻断可玩闭环，`P1` 为核心体验，`P2` 为表现和兼容性。
- 规则夹具可以直接构造棋盘状态；不得把夹具入口加入正式关卡或用作弊方式代替完整流程验证。
- 除非案例另有说明，预期中的“拒绝”均指状态不变、不消耗该单位行动、不给经验/金币，也不触发动画或回调。
- 所有涉及“预览”的案例，都要同时断言预览查询无副作用，并在实际提交/结算后与预览结果一致。

## 3. 纯规则测试

### 3.1 棋盘、行动与基础走法

| ID | 类型/优先级 | 前置与操作 | 预期结果 |
| --- | --- | --- | --- |
| R-001 | R / P0 | 主帅在 `(4,0)`；分别尝试到 `(5,0)`、`(4,2)`、`(4,1)`；在宫边尝试越界。 | 到 `(5,0)`、`(4,1)` 的正交一步合法；跨两步及越出九宫均被拒绝且不耗行动。 |
| R-002 | R / P0 | 双方分别测试九宫中心到八个相邻位置、四角到中心、跨中心直达对角，以及边中点任意斜走；再布置友军/普通敌人于斜步目标。 | 中心八邻点与角点到中心合法；跨步、边中点任意斜走非法；友军阻挡，普通敌人可吃。斜步可解围，查询/预览/实际结算一致。 |
| R-003 | R / P0 | 车在 `(0,0)`；依次测试移动到同列/同行空格、攻击直线普通敌人、隔着友军攻击敌人、试图落在友军格。 | 空格移动合法；攻击后车占据被击杀普通敌人的格；后两项均被拒绝。 |
| R-004 | R / P1 | 马可走日字的两种局面：马腿空；马腿格分别被己方和敌方占据。 | 马腿空时目标合法；任意阵营单位占据对应马腿时，该马步非法。 |
| R-005 | R / P1 | 炮与目标同线；分别布置 0、1、2 个中间单位。另测试炮移动路径中有单位。 | 仅恰有 1 个炮架时攻击合法；0 或 2 个炮架攻击非法；普通移动不能越过任意单位。 |
| R-006 | R / P1 | 敌卒在 `y=5`、`y=4`，分别查询前进、横移与后退动作。 | `y=5` 只可向 `y` 减小方向前进；到 `y≤4` 后可横移一格；始终不可后退。 |
| R-007 | R / P1 | 任一未行动单位分别对空位、敌方、友方格发出移动/攻击指令；重复提交一次已行动单位。 | 空位仅可合法移动、敌方仅可合法攻击、友方格不可落子或攻击；成功动作每回合只消耗一次行动，重复提交被拒绝。 |
| R-008 | R / P1 | 分别攻击普通敌人、主帅、敌将；目标血量设为 1 的敌将也覆盖。 | 普通目标立即移除且攻击者占目标格；攻击主帅/敌将仅扣 1 HP，攻击者留在起点；1 HP 敌将仍按“敌将”规则处理。 |
| R-009 | R / P1 | 查询合法动作与动作预览；对同一状态重复调用后再比较完整状态。 | 返回目标、类型和路径；棋盘、HP、XP、金币、回合、行动次数与单位位置均不变化。 |

### 3.2 车贯穿、经验与升级

| ID | 类型/优先级 | 前置与操作 | 预期结果 |
| --- | --- | --- | --- |
| R-010 | R / P0 | Lv.1 车同线面对两个普通敌人，选择第二个敌人为最远目标。 | 因接触敌人数超过等级上限而拒绝；车与敌人均不变。 |
| R-011 | R / P0 | Lv.3 车同线面对三个普通敌人（敌人间可有空格），选择第三个。 | 三个普通敌人依近到远全部移除，车停在第三目标原位置，只消耗一次行动。 |
| R-012 | R / P0 | Lv.3 车路径为“普通卒 → 2 HP 敌将 → 普通卒”，选择第三个卒。 | 首卒阵亡；敌将 HP 变为 1；第三卒保留；车留在行动起点。 |
| R-013 | R / P1 | Lv.2/3 车的路径中先遇到主帅或 1 HP 敌将，后方仍有普通敌人。 | 有血量单位受 1 点伤害后整次贯穿停止；后方单位不受影响；车不移动。 |
| R-014 | R / P0 | 车 XP=1、Lv.1，击杀 1 个普通敌人；另设 XP=3、Lv.2，单次击杀 1 个普通敌人。 | 动作结束后分别升级 Lv.2、Lv.3；等级门槛为累计 2/4 XP。 |
| R-015 | R / P1 | Lv.1 车 XP=1，本次仅按 Lv.1 合法的攻击击杀 1 人；检查结算中和结算后可攻击范围与行动次数。 | 本次不能因将升级而多穿一人；结算后等级更新；不返还行动。 |
| R-016 | R / P1 | 以车、其他友军分别击杀敌人；第一波斩将导致其他敌人退场。 | 仅车亲手击杀普通敌人增加车 XP；友军击杀、对将造成伤害和波次退场均不增加 XP。 |
| R-017 | R / P1 | 车升级后检查 HP、单回合行动数与单次伤害。 | 车始终 1 HP、每回合一次行动、对有 HP 单位每次只造成 1 点伤害；升级仅改变贯穿上限。 |

| R-020 | R / P0 | 生成敌车攻击意图后，玩家移动另一枚己方单位到原目标位置。 | 敌车攻击新的占位己方单位；意图的目标位置不变。 |
| R-021 | R / P1 | 生成车、马、卒或将的攻击意图后，使原目标变空且该格不再是合法普通移动。 | 该意图原地取消；不得临时选取其他目标。 |
| R-022 | R / P0 | 敌炮有攻击意图；玩家移走唯一炮架。另设原目标移空但仍保留恰好一个炮架。 | 前者取消且原地不动；后者原地打空，不移动、不换目标。 |
| R-023 | R / P0 | 两个敌人预告占据同一空格，且前者序号更小；结束回合。 | 前者按实际棋盘执行；后者因目的地被敌军占据而取消。预览与实际结算一致。 |
| R-024 | R / P1 | 前序敌人移动后，分别令后序敌车道路被堵、敌马马腿被堵、敌炮炮架数改变。 | 每步在前序动作后的实际棋盘重新校验；三类后序意图依规则执行或取消。 |
| R-025 | R / P1 | 玩家在敌方阶段前击杀一个已预告行动的敌人。 | 该单位待执行意图被删除，不执行、不造成伤害。 |
| R-026 | R / P1 | 进入波次后不进行任何玩家动作；检查初始意图，再结束回合并检查下一轮。 | 先生成并展示意图，敌人不会抢先行动；敌方结算完才按新棋盘生成下一轮意图。 |

## 6. 回归准入与交付判定

- 合并前至少通过全部 `P0` 规则与集成测试；代码或配置改动影响走法、意图、将死、奖励、波次或重开时，执行关联 `P1` 回归。
