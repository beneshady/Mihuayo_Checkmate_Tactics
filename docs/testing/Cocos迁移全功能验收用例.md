日期：2026-10-27。本文是待执行的测试用例，**不代表 Cocos 版本已通过测试**。执行目标为另一台机器上的实际 Cocos 项目；本地网页版本和策划文档仅用于核对预期。

## 一、执行说明

1. 记录被测项目版本、运行环境、启动入口及执行日期。先在桌面环境从正常入口实际操作；手机端不在本次必测范围。
2. 主流程不得通过注入金币、SP、关卡状态或直接跳转绕过正在验证的步骤。规则边界允许使用独立测试关卡、测试存档或可控随机数，但必须与正常流程分开；不要覆盖玩家真实存档。
3. 每个编号及其列出的各分支都要分别执行，记录通过、失败、阻塞或待确认及实际结果。入口缺失、功能未实现应明确记录，不得因无法进入就标为通过。状态、伤害和资源变化以实际结算结果为准，预览不能代替执行。
4. 文中坐标采用玩家视角的**列、行均从 1 开始**：左下角为（1，1），我方在下方，敌方在上方。默认棋盘为 9×9，河道第 5 行，桥位于第 2、5、8 列。测试布局应保持双方主帅存活，避免无关单位提前结束战斗。
5. 本文采用近期已确认的规则；旧版方案被后续规则替代时，以后续规则为准。将帅直视为已确认的新需求，旧网页版本尚未交付，执行时应区分未实现需求与迁移回归。
6. 执行前确认 Cocos 版本及实际交付范围。本文覆盖完整已确认方案；若与目标版本约定范围不一致，单独记录而不自行删减。

## 二、启动、教学与完整旅程

| 编号 | 前置条件及操作 | 预期结果 |
| --- | --- | --- |
| FLOW-01 | 全新玩家数据启动游戏，等待加载，进入开始界面。 | 加载完成且界面可操作，无卡死、遮挡或明显资源缺失。 |
| FLOW-02 | 新玩家选择开始旅程，尝试跳过第 0 关。 | 首次需完成教学，不能通过普通入口绕过。 |
| FLOW-03 | 按教学提示查看敌方意图、移动、撤销、攻击、结束回合并完成教学。 | 每步有可理解提示且可完成；完成后进入主营地。 |
| FLOW-04 | 教学关失败或退出后重新进入。 | 可重新进行教学；未完成不能误记为已完成。 |
| FLOW-05 | 教学完成后新建旅程，选择跳过教学。 | 可以跳过并进入主营地；教学完成标志保留。 |
| FLOW-06 | 正常完成教学并检查进入主营地的资源、队伍。 | 教学中获得的猫粮按规则保留；教学临时 SP、升级、伤亡不带入正式队伍；首次入营奖励另行发放一次。 |
| FLOW-07 | 从主营地打开选关地图，依次通过第 1、2、3 关。 | 教学不算三关之一；各关完成后按顺序解锁下一关，第三关胜利后结束旅程。 |
| FLOW-08 | 三个正式关分别持续至第二波出现并完成关卡。 | 每关可经历两波；第一、二关胜利后回营地，第三关结束后不额外进入下一关。 |
| FLOW-09 | 新旅程依次查看三关，尝试选择未解锁关及已完成关。 | 关卡提前可见；仅可进入当前解锁关，不能跳关或重玩已完成关。 |
| FLOW-10 | 在选关地图查看各关预览。 | 可辨别地图地形和首波敌方站位；未到预告时机不提前泄露第二波位置。 |
| FLOW-11 | 正式关失败后选择重试；另一次选择退出关卡。 | 重试恢复入关快照；退出关卡后的入口和进度符合游戏提供的退出流程，不能误发胜利奖励。 |

## 三、主营地、人口与资源

| 编号 | 前置条件及操作 | 预期结果 |
| --- | --- | --- |
| CAMP-01 | 新旅程首次进入主营地，记下猫粮和增益；离开后再次进入。 | 首次额外获得 8 猫粮和普通队友最大生命 +1；不重复领取。 |
| CAMP-02 | 首次进入营地查看引导；跳过后再进入，使用帮助入口。 | 引导说明招募、人口、增益和费用；允许跳过，不强制消费，可再次查看帮助。 |
| CAMP-03 | 检查初始正式队伍。 | 帅、两个普通兵、一马、一车；没有初始弓、枪、炮、象和仕。 |
| CAMP-04 | 查看持有数量和可部署数量，持续购买普通棋子超过部署上限。 | 持有队友与上场人数分别计算；超出部署上限的队友进入后备，不自动替换上场棋子。 |
| CAMP-05 | 初始部署上限为 4，消耗猫粮逐次升级至上限并再次尝试。 | 每次 5 猫粮，上限每次 +1，最高 8；达到上限后不扣费、不继续增长。 |
| CAMP-06 | 猫粮不足 5 时尝试增加部署上限或解锁付费增益。 | 操作失败且余额、状态不变。 |
| CAMP-07 | 分别购买兵、炮、车、马、仕、象。 | 价格分别为 3、8、5、5、5、5 猫粮；成功后只扣一次对应费用。 |
| CAMP-08 | 尝试直接购买弓兵或枪兵；连续招募同类普通棋子。 | 弓和枪通过兵转职获得；同类普通棋子拥有独立身份和成长。 |
| CAMP-09 | 购买两座仕后再购买第三座；检查普通部署计数。 | 最多持有两座仕；仕和帅不占普通可部署人口。 |
| CAMP-10 | 有空部署位和无空部署位时分别购买普通棋子。 | 有空位自动进入出战队伍；无空位进入后备。 |
| CAMP-11 | 在营地调整出战及后备，达到上限后尝试增加出战人数。 | 可在限制内选择；不能超过上限；已持有棋子不会丢失。 |
| CAMP-12 | 多次快速点击购买、升级人口及解锁增益。 | 每次有效交易只发生一次；余额不足时不能重复扣费或生成重复奖励。 |
| CAMP-13 | 在战斗中由不同我方棋子分别击杀敌人，再打开另一枚棋子的升级。 | 击杀获得的 SP 进入公共资源，可用于其他棋子；友军死亡不产生敌方击杀奖励。 |
| CAMP-14 | 关卡内击杀普通敌人及敌将，分别胜利与失败。 | 胜利按普通敌人每个 1 猫粮、敌将 5 猫粮结算一次；失败不发放关卡奖励。 |
| CAMP-15 | 以牵引或碰撞击杀敌人，检查击杀归属和公共 SP。 | 归属于对应施法或攻击单位，奖励不重复。 |
| CAMP-16 | 使用牵引车通关：分别让其存活出战、阵亡、处于后备，再比较失败场景。 | 每个存活且出战的牵引车在胜利结算时额外给公共 SP 1 点；后备、阵亡或失败不获得。 |
| CAMP-17 | 普通队友死亡或受伤后胜利，进入营地并开始下一关。 | 队友恢复满血，已购成长和身份保留；新关使用新棋盘状态。 |

## 四、主帅增益与救援

| 编号 | 前置条件及操作 | 预期结果 |
| --- | --- | --- |
| BUFF-01 | 首次入营后查看普通队友、帅、仕的生命。 | 普通队友获得生命上限 +1；帅和仕不获得。 |
| BUFF-02 | 花 5 猫粮解锁移动增益，再花 5 解锁救援；尝试逆序和重复解锁。 | 按生命、移动、救援顺序解锁；已解锁效果同时生效；逆序、重复不扣费。 |
| BUFF-03 | 解锁增益前后各招募普通队友，并在关卡间切换。 | 已有、后备和新招募的普通队友继承适用增益；跨关保留，不重复叠加。 |
| BUFF-04 | 使用移动增益测试兵、车、炮、马、象。 | 普通移动范围按各自规则增加；不增加攻击、冲锋、跳跃或施法技能射程。马和象的具体落点见后续用例。 |
| BUFF-05 | 未解锁救援时进入第二波；已解锁时再次进行。 | 未解锁不出现救援选择；解锁后每关第二波开始前最多使用一次。 |
| BUFF-06 | 第二波前有受伤普通队友，选择该队友。 | 该队友回满血；其他单位生命不变；救援次数耗尽。 |
| BUFF-07 | 阵亡普通队友尸体仍在原格，选择复活。 | 在尸体所在格复活为 1 HP；该尸体消失；身份与成长保留。 |
| BUFF-08 | 分别尝试选择满血队友、帅、仕、尸体已消失的阵亡队友、敌人及后备队友。 | 均不能作为救援目标。 |
| BUFF-09 | 有合法目标时主动跳过；另设无合法目标。 | 可跳过；无合法目标自动跳过；未使用次数不累计到下关。 |
| BUFF-10 | 在敌方预告出生点复活友军并继续出生结算。 | 复活单位阻挡当次出生并受 1 点伤害；即使因此死亡，该次出生仍被阻挡。 |

## 五、地图、布阵与地形

| 编号 | 前置条件及操作 | 预期结果 |
| --- | --- | --- |
| MAP-01 | 未绑定自定义地图，检查三关默认地图。 | 均为 9×9，有双方九宫、第 5 行河道和第 2、5、8 列桥；地形一致。 |
| MAP-02 | 检查默认首波敌方阵容。 | 3 兵、1 车、1 炮、2 士、1 将，共 8 个。 |
| MAP-03 | 进入布阵后尝试返回主营地、重新购买或通过菜单绕过。 | 开始关卡后不能返回营地修改入关准备；继续和重试遵守入关快照。 |
| MAP-04 | 在合法空格布阵，分别尝试越界、敌方半场、山、水和已占用格。 | 合法位置可布置；不合法位置被拒绝且原位置不丢失。 |
| MAP-05 | 普通出战队伍为空、1 个、上限个及超上限时分别确认布阵。 | 空队伍和超上限不能开始；1 至上限内可开始；帅与仕不计入普通人口。 |
| MAP-06 | 分别布置一座或两座仕，尝试左右侧位切换，侧位被普通队友占据时操作。 | 仕只在我方九宫左右中间固定侧位；被占时提示先移开，不挤走队友。 |
| MAP-07 | 检查河道水和桥；尝试破坏桥。 | 水与桥可区分；桥按普通陆地通行、占位，不可摧毁。 |
| MAP-08 | 对完整山造成一次、再造成一次有效山体伤害。 | 完整山变开裂山，再变碎石；碎石按普通地块通行，不再阻挡或充当炮架。 |
| MAP-09 | 单位撞上剩余一次耐久的山。 | 本次撞击只计一次山体伤害；山变碎石，单位本次仍停在山前，不穿过去。 |
| MAP-10 | 将尸体推入水；再将尸体推到桥。 | 入水尸体销毁；桥为普通陆地，尸体可停留。 |
| MAP-11 | 在树林分别构造命中和闪避分支，使用直接攻击并比较碰撞伤害。 | 直接攻击按既定 30% 闪避判定；闪避不受该次直接伤害及其附带推动；碰撞伤害不闪避。 |
| MAP-12 | 连续查看和取消预览，再执行同一攻击。 | 预览不改变血量、位置、资源、地形或随机状态；实际执行才结算。 |

## 六、回合、敌方意图与出生

| 编号 | 前置条件及操作 | 预期结果 |
| --- | --- | --- |
| TURN-01 | 开始正式关，观察敌方准备、我方回合和敌方行动。 | 敌方先移动并展示意图；我方行动、结束回合后，敌方按预告执行。 |
| TURN-02 | 鼠标指向不同敌人，观察棋盘；移开鼠标。 | 对应敌人的攻击方向、目标及危险格清楚显示，不改变战局。 |
| TURN-03 | 敌人锁定方向后，移走原目标，结束回合。 | 敌人仍沿原锁定意图攻击，不追踪逃离的目标；空格不受伤。 |
| TURN-04 | 将已锁定意图的敌人推拉至新位置。 | 攻击方向保持，起点和相对落点随敌人新位置改变；不是追踪原目标。 |
| TURN-05 | 杀死已预告的敌人；另设炮架或射线发生变化。 | 死亡敌人不再攻击；不满足攻击条件时该次攻击失效，不临时另选目标。 |
| TURN-06 | 改变敌方攻击线上单位，使另一敌方单位进入攻击范围。 | 按锁定攻击实际命中对象结算，可发生敌方误伤。 |
| TURN-07 | 多个敌人预告攻击，结束回合。 | 按已展示顺序结算；前一次伤亡或地形变化影响后续实际有效性，不重复行动。 |
| TURN-08 | 将局面推进到第 5 回合和第 6 回合。 | 第 5 回合显示第二波出生预告；第 5 回合敌方行动结束后，在第 6 回合开始前处理救援与出生。 |
| TURN-09 | 第 5 回合结束时首波普通敌人仍存活。 | 第二波仍按固定时机出现，首波剩余敌人保留，不等待清场。 |
| TURN-10 | 第二波出生格分别为空、友军、友军死亡后留下的尸体、敌军。 | 空格正常出生；友军受 1 伤且阻挡本次；尸体在后续出生尝试时被清除；敌军占格时不误伤敌军，处理细节按已交付规则记录。 |
| TURN-11 | 阻挡出生后持续推进至第 11 回合。 | 未出生单位按后续回合重试；不产生第三波；未出生敌人不计击杀收益。 |
| TURN-12 | 第 11 回合结束前不击杀敌将但保持我方帅存活。 | 完成该回合敌方行动后胜利并结算一次。 |
| TURN-13 | 提前击杀敌将；分别使我方帅死亡及双方同时死亡。 | 敌将死亡触发胜利；我方帅死亡触发失败；双方同时死亡按我方失败优先。 |
| TURN-14 | 暂停、切到其他窗口、恢复。 | 战斗不会因失焦自行推进回合或重复结算；恢复后可继续操作。 |

| SOLDIER-13 | 有移动增益的未过河兵尝试直线前进 2 格。 | **待确认**：近期策划写未过河仍 1 格，旧实现静态检查显示可能允许 2 格。记录实际表现，暂不单凭此项判定迁移缺陷。 |

## 八、车与转职

| --- | --- | --- |
| ROOK-01 | 初始车在无障碍直线分别移动 1～4 格，尝试第 5 格及斜向。 | 基础移动最多 4 格，只走直线；超距和斜向不可。 |
