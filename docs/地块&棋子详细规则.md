# 地块&棋子详细规则

本游戏的地块和棋子规则主要参考中国象棋

## 1. 地块种类

1、平地（plain）：所有棋子可以正常走的地块

2、森林（forest）：对所有棋子来说等价于无法攻击的棋子单位，不能走到这上面

3、水面（water）：对部分棋子而言等价于平地（如兵、车、马等等）对另一部分棋子而言等价于森林（如象）

4、地宫（raod）：对大部分棋子而言等价于平地，但是对 【士】、【将】 来说他们只能在地宫上进行移动

## 棋子种类及移动规则

现在给每个棋子再加上体力的属性，每回合体力回满，但是攻击和移动会消耗体力点，体力点的信息也要加入点击棋子后的信息面板中

| 棋子 | 移动规则                                                     | 攻击规则                                                     | 备注                                   |
| ---- | ------------------------------------------------------------ | ------------------------------------------------------------ | -------------------------------------- |
| 帅   | 无法移动                                                     | 无法攻击                                                     | 通常生成在地宫块上，无法移动也无法攻击 |
| 车   | 沿着4个方向直到碰到障碍（森林格、其它棋子等）与实际象棋规则一致 | 只能攻击上下左右方向一个内的敌人                             |                                        |
| 马   | 马走日，除非别马脚（被森林格、其它棋子别）与实际象棋规则的马一致 | 与马的移动规则一致                                           |                                        |
| 炮   | 与车的移动规则一致                                           | 可以隔着障碍（森林格、其它棋子等）对其他敌方单位进行攻击，类似际象棋规则的炮 |                                        |
| 象   | 马走田，除非别象脚（被森林格、其它棋子别）与实际象棋规则的马一致，同时，象不能踩到水面上 | 以它为一点的田字范围内的所有方块都是攻击范围，但是不能攻击水面上的敌人 |                                        |
| 士   | 只能在地宫块上斜着移动一个单位                               | 能攻击其附近的8个内的任一敌人                                |                                        |
| 兵   | 只能在地宫块上直线移动一个单位                               | 与兵的移动规则一致                                           |                                        |
