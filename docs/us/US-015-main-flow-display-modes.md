## 确定范围与最小默认

1. `index.html` 首页主菜单显示“网页版 / 手机版”控件及当前选中状态，能键盘操作且有可访问名称。无需新开页面才能切换。
2. 首次无显式选择时，沿用现有屏幕宽度断点给出默认模式；手动选择优先，不因普通 resize 立即被覆盖。至少在当前页面旅程内保留选择，不要求新增跨会话存档或云同步。
3. 网页版使用现有电脑布局；手机版使用 preview 已有手机布局。桌面选择手机版也应明显呈现竖屏手机布局（可复用 448×924 视口及缩放方式）；真实窄屏须适应可用宽高，不能直接按硬件像素渲染。
4. 两种模式都从同一套 Loading→主菜单→三关地图→部署→主帅增益→战斗→结算/商店→下一关流程运行。首次 Loading 默认按当前屏幕适配；切换模式不要求重播 Loading。
5. 切换只影响呈现，不新建旅程、不重载游戏实例、不清空金币/成长/当前棋局。已有旅程从暂停返回首页切换后，“继续游戏”恢复原关、回合、队伍、金币与敌方意图；不得触发新旅程确认或重开。只要求首页有切换入口，不强加战斗中悬浮切换控件。
6. 保留原 preview 预览工具、关卡编辑器和夹具入口；不递归嵌套 iframe，不复制一份战斗或奖励逻辑。具体复用方式由开发选择，以最小改动为准。
7. 保持纯静态网页，无新增构建/后端/外网依赖；本次新增切换和加载不得破坏 `file://.../web/index.html` 的可用入口。存储不可用时不得阻塞基本流程。
