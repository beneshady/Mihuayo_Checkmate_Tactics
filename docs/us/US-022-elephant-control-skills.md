# US-022：象的牵引与冰封

日期：2026-10-24。状态：用户已确认方案并授权开发；**已实现并完成 Harness 定向自测 + 真实浏览器验收，待主策划审阅（不等于已验收）**。价格及控制强度平衡为 TBD。

关联：US017 公共 SP、US019 主帅、US020 主营地/保存、US021 马。本文替换旧象的雷击、斜移3格、冰封隔回合使用等候选方案，不改写历史验收。

## 1. 基础与范围

- 我方象为控制法师，基础1 HP，普通队友血量增益生效后2 HP。主营地5猫粮购买，可多只，不加入初始两个兵、一个马、一个车阵容。
- 普通队友持有/后备/部署人口、救援、公共SP和旅程规则统一。公共SP只强化选中的象，不改变其他象。
- 初始牵引，2 SP解锁冰封后两者保留；不新增普通伤害攻击或雷击。敌方不新增象技能，不改共享经验经济。
- 复用现有UI、规则、存档，不重做教学、美术、布局或技能框架。

## 2. 移动、行动与保存

- 基础走田：斜向恰好2格，检查中间象眼，棋子/尸体/山体阻挡；最终格不能被占据或是山体。可进入河道水格并施法，不可进入敌方半场。
- 主帅移动增益：合法田字落点加上下左右邻格，原落点仍可选，一次点击最终格，不先落田字点再点一步，不改为斜走3格。象眼、参照落点及最终格须合法，最终格不能越界、被占或进敌方半场；多条合法路线合并去重。此处按已确认“合法田字落点”口径，不照搬马参照格可占用的特例。
- 每回合一次普通移动和一次技能；可先移后施法或直接施法。成功施法后不能再移动。牵引/冰封共用技能次数，无额外冷却。
- 普通移动可撤销、不单独保存；成功施法即使无伤害也锁定此前撤回并保存。成功升级也保存并锁撤回，不消耗或恢复行动。取消/非法选择/失败购买不扣费、不耗行动、不提交保存。
- 沿用营地/布阵/战斗合法阶段的升级入口、跨关保留、失败回入关快照、新旅程重置。无新增其他象升级；已有通用升级若存在则保留，不擅自删改。

## 3. 牵引

### 3.1 选取与升级

- 初始四正交方向同线最大3格；每1 SP四方向一起+1，上限8格。实际距离1不可选并提示太近；不能选自己。
- 可以选择友军、敌军、尸体，包括我方主帅；不能选择我方仕、山体。主帅出宫后沿用宫外移动规则。
- 施法可以越过棋子、尸体、山体选择后方指定目标，不是只选第一个对象。射弹无直接伤害。
- 位移距离为 `floor(目标到象的实际距离/2)`，不是最大射程的一半。距离2/3→拉1，4/5→2，6/7→3，8→4。
- 象不能过河只约束自身移动，不限制两种技能跨河选敌方半场目标。

### 3.2 位移与碰撞

- 目标朝象逐格移动，实际位移不穿越障碍；首次碰撞即停止，不连锁推动，不传递撞击。不与施法象相撞，最多停在旁边。
- 活体撞活体双方各受1伤；没有碰撞只是位移没有伤害。活体撞山：目标受1伤、山受一次撞击。活体撞尸：目标受1伤、尸体保留。
- 尸体可被拉：自身无HP，撞活体/山让对方受1伤，尸体保留；尸体撞尸体仅停止、双方保留且无伤。
- 不能入水的单位进入路径首个水格立即死亡并终止牵引；尸体入水销毁。桥按普通陆地；其他单位既有非致死水规则不更改。
- 多象互拉也不能进敌方半场，最多停在河道，半场限制不造成碰撞伤害。
- 环境/碰撞敌军击杀归属施法象，沿用击杀成长与公共SP奖励，不重复记奖，不奖励友军死亡。
- 未冻结敌人被位移仍沿用锁定方向、落点随位置变化的意图规则。未明确覆盖的既有固定装置及敌方宫域限制保持，冲突报告，不推导新玩法。

## 4. 冰封

- 2 SP一次性解锁，初始冻结1个敌方行动阶段；每2 SP+1，最多3。升级只增加持续时间。
- 固定以自身为中心5×5（横纵差各≤2），含斜向、截去棋盘外。选单个敌人，包含敌将；不选友军、尸体、山。不是群攻，不造成直接伤害。
- 施法不受单位、尸体、山遮挡，可跨河。无额外冷却，可连续回合冻结同一敌人，但仍与牵引共享一次技能机会。
- 冻结期间不能移攻、能被位移。UI直接变为“待机”，不显示原攻击意图。每个敌方行动阶段跳过行动并递减；到期恢复正常新意图，不补打跳过攻击、不无预告偷袭。
- 实际受伤清除所有剩余冻结回合，但本回合仍待机不行动，下回合恢复。无伤位移不解冻；碰撞受伤同样解冻，无额外碎冰伤害。
- 受伤发生在敌方阶段也不能在该阶段后续恢复行动，不额外吞掉下一整回合；须按回合身份实现并验收阶段顺序。
- 重复冰封不叠加、不缩短，取剩余时间和本次持续时间的较大值，消耗施法象机会。
- 受伤解冻后同回合另一只象可重新冰封，赋予完整本次时长，消耗另一只象技能次数。

## 5. 统一山体规则

- 所有技能导致的单位撞山：山体2耐久，每次碰撞只扣1，累计两次变碎石地；牵引一次不是直接撞碎。
- 碎石地等同普通陆地，仅视觉区分；可移动、不占位、不阻挡、不作为炮架。用简单标识即可，无需新素材。
- 山被撞毁当次仍停在山前，不继续穿过刚生成的碎石地；之后才可通行。
- 复用已有累计受击状态，直接攻击既有山体受击次数规则保持，不拆两种耐久。马直接攻击一次后再有效撞击一次可累计坍塌。
- 不改其他技能原有多对象碰撞算法，只统一撞山计数/坍塌；象自身牵引不连续撞击。
- 保存恢复保留山受击/碎石；新关重置地形，不污染地图模板。
