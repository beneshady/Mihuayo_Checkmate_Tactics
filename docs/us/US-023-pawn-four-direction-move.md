# US-023 兵系四向走法：进入敌方半区后可前后左右移动（编号暂定）

> 需求来源：用户直接指示「兵（以及专职）进入敌方半区后可以前后左右移动」（2026-10-24）；
> 同日二次确认：**只有我方兵在敌方半区四向移动，敌方兵进入我方半区仍只能前/左/右（不能后退）**。
> 本文件编号 `US-023` 为本次开发会话暂定，若主策划已占用其他编号请直接改名。
> 工作分支：`codex/web-gameplay-validation`；未推送、未合并。

## 1. 规则改动

| 项目 | 改动前 | 改动后 |
| --- | --- | --- |
| 我方兵（`pawn`） | 未过河只能向前一步；进入敌方半区后可前 / 左 / 右 | 未过河只能向前一步；进入敌方半区后 **前 / 后 / 左 / 右** 一步 |
| 我方转职兵（`archer` 弓兵、`spearman` 枪兵） | 与兵相同（未过河只向前，过河后可前 / 左 / 右） | 与兵相同，过河后四向齐备（两者共用 `pawnish` 走法） |
| 敌方兵（`pawn`） | 进入我方半区（`y<=3`）后可前 / 左 / 右，不能后退 | **不变**：仍只能前 / 左 / 右，不能后退（本次改为单侧解禁） |
| 敌方转职兵 | 敌方没有转职兵 | 同左 |

保持不变的口径（未改动）：

- **过河判定仍按动作起点**：我方 `y>=5`、敌方 `y<=3` 算进入敌方半区；河道行 `y=4` 仍未过河。被推回或主动退回河道/己方半区后，当回合之后的移动重新受「未过河只能向前」限制（本次浏览器验收 N04 实测该回落）。
- 河道水格仍为兵系致死水格（`fatalWater`），后退落点或路径经过水格非法；只能走桥。
- 攻击形状与走法一致：我方过河兵可攻击身后相邻敌人，未过河兵不能攻击身后目标（A06）；敌兵不论是否过河都不会把身后的我方棋子当作目标（A08），敌方意图与改动前一致。
- 疾行（`commanderMove=1`）下我方过河兵可直行后退 2 格，未过河仍只 1 格（A04）。
- 转职后的四向技能攻击（弓/枪的方向攻击）不受本规则影响。
