## 2. 回合合同

### 2.1 敌方准备 → 玩家行动 → 敌方攻击

1. 开局、下一波入场以及每次敌方攻击结算完毕后，进入敌方准备。
2. 敌方按稳定顺序各获得至多一次普通移动（可不移动），只能移动到合法空格，不在准备阶段攻击、冲击、造成伤害或触发击杀成长。移动距离、棋种走法、九宫和阻挡沿用当前规则。
3. 所有敌方准备移动完成后，根据这一最终局面，为每个敌人生成至多一次攻击意图；无合法攻击则明确显示待机。本批意图统一冻结，然后恢复我方回合额度并交给玩家。
4. 玩家移动、攻击、升级、查看预览和撤销均不重新生成敌方意图。仅当前预计落点、伤害与有效性随局面刷新。
5. 玩家确认结束回合后，敌方按预告顺序各执行至多一次冻结攻击；这一阶段不新增普通移动、不补选攻击。
6. 结算结束且战斗继续，才进入下一次敌方准备。开场与新波次必须先给玩家处理意图的机会，不允许先扣血。

敌方 AI 采用最小确定性实现：准备时已有合法攻击就保持原位；否则按既有“接近我方帅、同距按坐标”的规则选择普通移动。逐个移动时使用实时占位，禁止叠子或穿子。全部移动完成后选攻击，优先帅、车、其他目标，同优先级沿用坐标排序。敌方次序采用稳定的出生/配置顺序，显示的攻击顺序必须等于实际执行顺序，不引入随机性或复杂搜索。

### 2.2 锁定相对攻击，而不是受害者

- 冻结攻击方式、方向、相对攻击距离/形状与顺序，不存活目标追踪，不锁死世界坐标。
- 最小实现口径：保存预告时“攻击格减攻击者位置”的相对位移。结算目标格 = 攻击者当前实际位置 + 原相对位移。直线攻击保持原方向和距离；不因被推而延长射程、缩短到另一个目标或旋转方向。
- 例如敌方车从 `(4,4)` 向 `(4,3)` 冲击，被横推到 `(3,4)` 后，仍向下冲击 `(3,3)`，绝不回头攻击原 `(4,3)`，也不追踪原目标。
- 对兵、士、将（及规则支持的马），保留原一步/日字相对形状。当前九宫、马腿等约束仍适用；不能合法执行就明确标记失效，不另选动作。
- 连续推动累计改变攻击者位置；撤销我方移动恢复对应局面与预测，但原冻结决策保持一致。

### 2.3 结算与干预

| 局面变化 | 结算规则 |
| --- | --- |
| 原受害者走开 | 攻击原相对落点，允许落空，不追击新位置 |
| 攻击者阵亡 | 跳过其攻击；后续顺序不重排 |
| 新落点被另一棋子占据 | 命中当前占位者，包括敌方自己的同伴；不能因为是同阵营而取消 |
| 敌人误杀敌人 | 不给我方任何棋子击杀升级、技能点或击杀统计奖励；敌方自身也不成长 |
| 炮的炮架变化 | 从当前炮位置到平移后落点之间仍须恰好一个炮架；不足或多于一个则失效，不搜寻替代目标 |
| 炮落点为空 | 炮架条件成立则射空；攻击力仍为2，敌方无扩散技能，只命中该落点一枚单位 |
| 冲击落点为空 | 路径合法则按既有车规则冲到落点；不产生伤害或成长 |
| 路径、宫界、马腿不合法或落点越界 | 本次攻击失效，显示原因；不新增绕行、穿透、碰撞伤害、替代目标 |
| 前序攻击改变后序的炮架、占位或存活 | 后序攻击使用执行时局面，但保持原意图与顺序；预览必须按同样的顺序预测 |

仅改变敌方冻结攻击的友伤规则；不把我方普通攻击改为可随意点杀友军，不改变我方炮现有扩散友伤、技能数值或推动限制。不新增尸体或地形系统。

### 2.4 胜负与波次

- 我方帅实际阵亡立即失败；不因危险提示或“无解”搜索提前判负、清除意图或禁用撤销。
- 敌将实际阵亡结束当前波；第一波保留原商店，第二波胜利。不把两波流程擅自改成单波。
- 主帅阵亡后停止后续敌方攻击和准备，不再对已结束波次移动、扣血或发奖励。
- 搜索可保留为提示辅助，但不能改变战斗状态。已有将死夹具、断言与 UI 文案须按此更新，不通过删除无关回归掩盖失败。

## 3. 展示与交互

- 非悬停时默认展示所有敌方攻击落点/威胁格及行动顺序，使用既有整格覆盖风格。重叠威胁不能无声覆盖丢失，可结合已有意图列表显示多个攻击者。
- 悬停敌人突出该敌人的方向、路径、预计伤害、顺序及当前结果（命中/落空/失效/待机），离开恢复总览与原选择。不再需要逐个悬停才能看到整体威胁。
- 推动、击杀、移动、撤销后立即更新预测；敌方尚未执行时不能伪造新的 AI 决策。失效攻击保留可读说明。
- 玩家攻击预览和敌方威胁采用可区分样式，不回退到格内圆圈。预览、详情与真正结束回合使用同一套结算语义。
- 保留 US-004 直接移动/撤销、US-005 我方炮移动后攻击与双额度，不增加攻击后移动。

## 4. 验收条件

| 编号 | 可观察结果与最低验证 |
| --- | --- |
| AC01 | 默认新局与第二波均先完成合法敌方准备，再展示意图并交给玩家；玩家第一次结束回合前无敌方伤害，准备无叠子、非法移动或重复执行。 |
| AC02 | 一个敌人可在准备阶段移动后预告攻击；攻击阶段只执行冻结攻击、不再普通移动；新回合只重新准备/生成一次意图。 |
| AC03 | 原目标移走时不追踪；受推敌人沿原方向、原距离在新位置攻击，横推与纵推、连续推动至少各有规则用例；不回打原绝对格。 |
| AC04 | 新落点可伤敌方同伴且不会给我方成长或击杀数；敌人提前阵亡跳过；落点空格时原地攻击落空、车合法冲空，均不伪发奖励。 |
| AC05 | 炮新路径恰好一个炮架才射击且单目标伤害2；覆盖炮架移走、增加第二架、推动炮后炮架成立/失效。宫界、越界、马腿、冲击阻挡不合法时有明确失效原因且不重选目标。 |
| AC06 | 默认整格展示全部威胁和顺序；悬停突出单敌；推后、撤销后、击杀后刷新正确，无旧格残留。含前序攻击改变炮架/杀死后序敌人的用例，预览与实际结算一致。 |
| AC07 | 帅活着时不会因将死搜索强制失败；帅实际阵亡立即失败；第一波杀将进商店、第二波杀将胜利；终局后不再执行后续敌方动作。 |
| AC08 | 我方车/炮双额度、直接移动、移动撤销与攻击锁定、暂停恢复、9×9点选、现有技能均回归通过；正式两波马/炮回放根据新流程重新生成并验证，不能把旧回放失效误报为新流程已通过。 |
| AC09 | 不触碰既有对局标签，不刷新/导航/关闭/注入、不清存储、不改全局视口、不停启已有服务；策划仅用新建独立标签试玩，不承诺正在进行的旧局热更新。 |

开发提供新的可复现意图试玩夹具：逃离目标、横推改线、误伤同伴、炮架变化、顺序连锁；夹具通过自然点击即可验证，不要求策划注入状态。默认新局及完整两波也必须验证，不能仅靠夹具。
