## 1. 目标、范围与优先级

将原关间商店整合为主营地，集中承接队伍恢复、招募、人口扩编、技能升级、旅程增益和新手指引。复用现有网页主流程、商店、技能、布阵、地图及快照逻辑，不重做战斗或新增引擎。

本文件是本轮确认后的目标合同，不表示当前游戏已经实现。以下覆盖旧方案，其他无冲突规则继续沿用：

| 旧方案 | 本轮最终方案 |
| --- | --- |
| 金币 | 对玩家统一称猫粮，替代而非新增钱包；既有收益数值不因改名改变 |
| 每关免费三选一，跨关替换 | 免费血量增益、付费顺序解锁移动和救援；已解锁增益同时生效，旅程内跨关保留 |
| 离营前必须选择 buff | 取消三选一及其离营阻塞 |
| 布阵可返回主营地 | 仅选关地图可返回；确认进入关卡后（包括布阵）禁止返回 |
| 开战时才保存准备结果 | 确认进入关卡时保存入关快照 |
| 教学可首次跳过、资源完全隔离 | 首次必须通过；曾完成者可跳过。教学成长不带出，实际完成所得猫粮保留 |
| 通用8人部署上限 | 初始4，5猫粮扩编1人，最多8；主帅和仕不占人口 |

不在范围：新兵种/技能、完整将帅直视、商店随机刷新、出售/遣散、永久战力成长、云存档、排行榜、地图编辑器重做。价格与强度平衡仍待实际观察，不以功能通过证明好玩或平衡。

## 2. 需求清单与规则

### R01 教学与主营地入口

- 第0关为教学关，不计入现有三个正式关卡；复用US016独立教学内容。
- 新玩家必须完成教学，失败只能重试，不能跳过进入主营地。完成教学指达成教学目标，不擅自要求击杀敌将。
- 曾实际完成教学的玩家，新旅程可跳过第0关；跳过不产生教学杀敌收益，也不能冒记一次实际通关。
- 完成教学或合法跳过后先进入主营地，不直接进入正式战斗。
- 完成与跳过使用同一套基础初始队伍、基础等级和0公共SP。教学中的伤亡、转职、技能升级不带入；实际完成教学所获猫粮保留，跳过不补发。
- 初始普通队友为车×1、普通兵×2、马×1（两个兵使用不同稳定 ID），无初始弓兵、枪兵、炮或仕；弓/枪只保留普通兵 2 SP 转职获取（2026-10-21 调整）。初始队伍已满血，血量增益另按R05应用。

### R02 旅程流程

```text
新旅程 → 第0关（曾完成者可跳过）
       → 主营地 → 选关地图 → 确认进入关卡〔保存快照〕
                           → 布阵 → 战斗（两波）
                           → 非最终关胜利结算 → 主营地
                           → 最终关胜利 → 通关结算
                           → 失败 → 重试当前关布阵〔恢复快照〕
```

- 从选关地图可以返回主营地调整，保留已购买人口、队友、解锁增益和技能，不退猫粮或SP。
- 确认进入关卡即离开准备阶段；布阵和战斗均不能返回主营地购物，也不能借菜单或恢复流程绕回购物。
- 最终关胜利后直接通关结算，不再回营；每个正式关卡仍为两波，不变更现有回合/出生节奏。
- 开启新旅程可以重置旅程，但不能把本关收益带回另一旅程。

### R03 猫粮、奖励与购买反馈

- 猫粮取代金币，结算、商店、顶部资源栏、提示、教学说明中统一用猫粮。内部兼容字段可保留 `gold`，不能因此出现两个钱包。
- 每次新旅程首次入营，额外发放8猫粮，仅一次；实际完成教学所得猫粮另加，合法跳过仅得这8猫粮。
- 失败重试、刷新、反复入营、返回地图不能重复发奖。
- 资源足够时允许一次回营连续招募、扩编、顺序解锁多个增益，不设每次回营次数限制。
- 不足时购买按钮禁用，保留价格；**不显示“还差多少猫粮”**。规则入口同样拒绝扣款。
- 对重复提交必须避免同一笔交易重复扣款/发货；合法的不同购买仍可连续执行。

### R04 普通队友持有数量、部署人口与招募

**2026-10-21 再确认；用户已授权开发，本轮已实施并完成 Harness 自测（P01～P08 + 双横版，待 Codex 审阅，见 5.11，不标记“已验收通过”）：** 持有数量与部署人口是两个独立显示概念，不能把部署上限当库存上限。以下补充优先于历史实现/验收措辞。

本次人口开发仅涵盖本节和关联界面/帮助/存档边界，复用既有计数及招募逻辑；已正确实现的规则不重写。保留兵2马1车1初始阵容与已确认保存规则，不迁移或清空用户旧局，不修改无关玩法。下列8项依次编号P01～P08，交付逐项写明前置、操作、实际结果、正常/专项分类、证据及最终哈希；至少一条正常入口真实招募路径，其余人数/余额边界可用标明的独立专项。网页与手机横版均核对关键人口文字、按钮和名单可读可操作，不扩展为全面UI重做。只跑相关回归，不重跑无关全套。历史“仅文档/未派发”记录保留为历史状态，不代表已验收；本轮实现与逐项证据见 5.11。

| 数值 | 定义与界面文案 |
| --- | --- |
| 队友总数 | 持有的普通队友总数＝上阵普通队友＋后备普通队友；不限数量。示例：`队友总数：7（其中后备3）` |
| 部署人口 | 本关选择上场的普通队友数量／部署上限。示例：`部署人口：4／4` |

- 新招募普通队友在有空余部署名额时默认上阵；满员进入后备，不自动替换已有队友。满部署及已达8部署上限都不阻止继续招募。
- 主帅与仕单独显示，均不计入上述普通队友总数、后备数或部署人口。主帅自动上场；仕仍最多持有两座、无装置后备。
- 允许不满编出战，但至少1名普通队友；玩家可在准备/布阵阶段调整上阵与后备，战斗中不换人。两个数值随名单调整同步更新，不能用同一“人口”标签混指库存和上场。
- 后续验收须覆盖：①持有7、上阵4、后备3、上限4的分别显示；②空位招募自动上阵、满员招募进入后备且原上阵不变；③部署上限8仍可持有9名以上普通队友；④5猫粮仅提高上限、不增加队友；⑤0人/超限拒绝、1人/上限人数允许；⑥主帅与两座仕单独计数；⑦刷新/失败重试恢复对应名单与部署上限；⑧新手帮助清楚解释上述两个概念。记录规则字段对照及实际浏览器文案/操作证据，未执行不得标通过。对应C07/C08/C09/C23/C24/C25/C26。

- 初始普通队友部署上限4；每次花5猫粮增加1，上限8，费用固定，不赠送第5人口。
- 人口限制上场普通队友，不限制持有普通队友总数；后备不占人口。
- 主帅自动上场，不占人口；仕不占人口、仍最多持有两座、无装置后备，侧位与冲突处理遵循US018。
- 允许不满编，但至少部署1名普通队友；主帅和仕不能代替这1名。超过当前人口不得确认布阵。
- 招募复用现有关间商店的兵种及价格，只改币种显示和所在页面，不改数值。炮保持8猫粮、仕5猫粮；其他兵种以实施前现有商店为基准，开发须在交付中记录价格对照。
- 新买普通队友可用于下一关布阵，有空余部署名额默认上阵，满员进入后备；不能覆盖或自动替换既有队友；不支持出售或遣散。

### R05 主帅旅程增益

| 增益 | 获得条件与费用 | 效果 |
| --- | --- | --- |
| 坚守/血量 | 每次旅程教学完成或合法跳过后首次入营自动获得，0猫粮 | 普通队友最大HP +1 |
| 疾行/移动 | 已有血量增益后，花5猫粮解锁一次 | 普通队友移动距离 +1，复用既有各兵种移动增益规则，不增加攻击距离或行动次数 |
| 救援 | 必须先解锁移动，再花5猫粮解锁一次 | 每关第二波开始前获得一次救援机会，详见R06 |

- 已解锁效果同时生效，不再提供互斥三选一，不每关替换，不重复购买或逐关叠加。
- 排除主帅和仕；普通上场队友、后备和新招募队友自动继承。
- 解锁立即更新主营地队伍属性及面板；反复切换名单、刷新、往返地图、跨关不得再次加同一份属性。
- 首次入营队伍满血，获得最大HP +1后当前HP同步为新上限；后续恢复按R07。不能用反复应用增益在关内回血。
- 旅程跨关保留，新旅程重置；失败重试采用入关快照。主帅仍无攻击和个人升级；猫粮解锁团队增益不是主帅个人技能升级。
- 救援未满足前置时禁用，明确提示“先解锁移动增益”；解锁后显示已解锁，不继续扣款。离营无需额外选buff。

### R06 救援

- 解锁后，每关第二波开始前触发一次，复用当前第5→6回合的波次衔接时点；不在每次敌方出生尝试时再次触发。
- 可选：当前战场受伤的普通队友，回复到含增益的最大HP；或尸体仍在的阵亡普通队友，于尸体当前位置复活为1 HP，并移除该尸体。
- 不可选：满血单位、主帅、仕/仕残骸、尸体已销毁的队友、非本场后备和敌方单位。
- 允许主动跳过，本关机会消耗、不累计到下一关；无合法目标自动跳过并继续第二波，不能卡在无选项界面。
- 选择/跳过后不能在本关再次救援；刷新不得重发。失败重试恢复入关状态，重新推进到第二波时可正常触发，不属于跨重试累计机会。
- 残骸推动、尸体入水销毁等沿用现有规则，不新增异地复活或复活后补到满血。

### R07 回营恢复与公共SP成长

- 非最终关胜利后进入主营地即执行原跨关恢复：队友满血、阵亡普通队友及被毁/毁骸的仕恢复，身份和成长保留；主帅状态沿用原跨关初始化。
- 恢复发生在关卡推进时，不在“地图→主营地”每次往返时额外执行奖励或成长。
- 公共SP仍为全队共享钱包，与猫粮分开。主营地可升级上场和后备队友；布阵及战斗仍允许使用SP，遵循各棋子已有升级条件、价格和上限。
- 主帅禁个人升级；仕只升级间隔，费用3/5 SP、3→2→1回合，不能治疗/强健；回营恢复不是关内治疗。
- 入关后新增的升级与SP消费均在失败重试时回滚到入关状态。

### R08 选关地图与预览

- 正式关卡全部提前可见，均可查看地形和第一波敌方初始站位；建议同时标识棋子种类以使站位可理解。
- 可预览不等于可进入：挑战资格仍按1→2→3逐关解锁，未解锁不可跳关。
- 本次旅程已通关关卡可查看，不可重打，不提供重复刷猫粮/SP入口。
- 第二波不提前显示配置或出生位置，按原战斗内预告规则显示。
- 预览与实际入关必须读取同一份有效关卡配置，包括编辑器替换后的地图；仅查看预览不创建战局、保存入关快照、扣费或推进解锁。
- 地图返回主营地保留准备成果；当前只有一个可挑战的下一关，不新增任意切换战斗路线的系统。

### R09 快照、保存与重置

- **确认进入关卡时**记录猫粮、人口、队伍及成长、公共SP、已解锁增益等入关状态，而不是完成布阵或第一次攻击时。
- 失败重试回到本关布阵，可重新决定名单/站位；恢复入关资源和成长，不保留本关新收益或技能购买，不能回主营地。
- 主营地购买、SP升级、增益解锁、首次奖励领取立即自动保存。刷新/退出后继续恢复最新有效状态，不撤销消费，不重复领取奖励。
