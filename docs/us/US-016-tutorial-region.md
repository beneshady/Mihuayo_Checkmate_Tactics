## 1. 用户目标与确定范围

作为首次游玩的玩家，我希望从初始地图进入一场简短的独立教学，学会查看敌方意图、移动、撤销、攻击和结束回合，再开始正式旅程；也可以在二次确认后跳过教学。

已确定的方向：

- 采用“独立教学关 + 正式流程首次提示”。
- 独立教学关在最开始的地图中表现为一个地区。
- 玩家可以跳过教学，但必须二次确认。
- 教学地区与关中、中原、江淮三个正式关卡并存。

下文是当前方案建议。地区名称、位置、具体战局、解锁方式、存储和提示细节均可继续修改；未验证项标记为 TBD。本次仅归档方案，不派发开发，不修改游戏、Excel 或正式 GDD。

## 2. 地图入口与流程

教学地区暂名 **演武场**，建议位于地图左下角，以小区域及旗帜表达，不作为真实历史疆域。它不计入三个正式关卡，也不提供正式旅程奖励。

建议流程：

1. 首次开始游戏后进入征战地图，默认选中演武场。
2. 地区介绍显示“进入教学”和“跳过教学”。
3. 完成教学或确认跳过后，返回地图并选中、开放第一关关中，不自动进入战斗。
4. 演武场保留重学入口，重学不影响正式旅程。


### 跳过的二次确认

| 项目 | 建议文案 / 行为 |
| --- | --- |
| 标题 | 跳过新手教学？ |
| 正文 | 你将直接挑战第一关。之后随时可以回到地图，进入演武场补学。 |
| 默认按钮 | 返回学习 |
| 确认按钮 | 确认跳过 |
| Escape / 点击遮罩 | 取消，不改变教学状态 |
| 确认后 | 标记已跳过，回地图选中关中，等待玩家进入 |

教学尚未处理时直接点击关中，建议提供“先去教学”和“跳过教学进入第一关”；后者仍须经过上述确认，确认后停留地图。教学过程中也保留跳过入口并复用确认弹窗。

单纯退出教学返回地图不算跳过、不算完成。再次进入未完成教学时从头开始。地图明确区分“待学习 / 已完成 / 已跳过”。

## 3. 独立教学战局

目标时长 **3–5 分钟（TBD，需新玩家试玩验证）**。复用 9×9 棋盘、现有棋子和战斗规则；桌面为菱形视图，手机为俯视布局。

建议全陆地，固定“坚守”增益，暂不在教学中讲部署和增益选择。使用我方帅、车、枪兵，敌方两个兵及远处的将。棋子、增益和敌方行为须按实施时的实际规则重新校验，特别是将帅直视规则的影响。

坐标使用从 1 开始的 `(列, 行)`：

| 单位 / 目标 | 建议初始坐标 | 用途 |
| --- | --- | --- |
| 我方帅 | (5,1) | 说明保护目标与 HP |
| 我方车 | (2,3) | 移出预警格、练习撤销 |
| 我方枪兵 | (7,3) | 攻击并消除威胁 |
| 敌兵① | (2,4) | 攻击车原位置，最终打空 |
| 敌兵② | (7,4) | 被枪兵消灭，不再执行攻击 |
| 敌方将 | (5,9) | 正常准备阶段安排到远处待命；具体行为 TBD |
| 车的安全目标格 | (3,3) | 教学指定移动目标 |

战术关系示意（非完整棋盘）：

```text
敌兵① ↓                    敌兵② ↓
   [车] → [安全格]             [枪兵]
                                ↑ 反击
               [我方帅]

     离开受击格           消灭发起攻击的敌人
```

### 教学步骤

| 步骤 | 玩家操作与提示 | 推进条件 |
| --- | --- | --- |
| 1 保护主帅 | 高亮帅与 HP：“保护我方主帅。先学会处理眼前的两次攻击。” | 点击“知道了” |
| 2 查看敌情 | 桌面悬停敌兵①，手机点击查看其攻击路径 | 攻击路径实际显示 |
| 3 移出危险 | 选择车，移动到指定安全格 | 移动成功 |
| 4 学会撤销 | 撤销刚才移动，再完成相同移动 | 位置与行动额度正确恢复，随后移动成功 |
| 5 消除威胁 | 选择枪兵，攻击相邻敌兵② | 敌兵②死亡且消耗正确的行动额度 |
| 6 结束回合 | 展示未行动提醒，说明此时主帅可以原地待命；结束回合并确认 | 敌兵①打空，敌兵②不再执行攻击，我方未受伤 |
| 7 完成教学 | 显示“返回地图，开始出征”，也可选择重学 | 实际完成目标后记录完成；返回地图选中关中 |

桌面保留点目标直接攻击；手机沿用预览后执行的操作。除说明步骤外，不用“下一步”代替真实操作。教学仅开放当前步骤需要的操作；误点给简短提示，不扣资源、不消耗行动、不推进步骤。

完成条件为上述教学目标，不要求击杀敌方将。教学资源、伤亡、行动与奖励均不得带入正式旅程。

## 4. 双端呈现与正式流程首次提示

### 教学呈现

- 桌面：目标附近放小提示卡，弱化无关区域，避免遮住棋盘和操作目标。
- 手机：复用棋盘下方预览区，不叠加额外页面高度；棋盘与当前必需按钮在一屏内可见，不依赖页面下滚。
- 提示正文尽量两行；使用描边、箭头和文字共同表达，不只依赖颜色。
- 手机点击敌人查看意图后，应能顺畅重新选择我方棋子；具体交互需验证。
- 战斗日志等次要信息沿用收起展开方式。

### 首次提示建议清单

正式流程中首次遇到时提示一次，并允许在帮助中复看。跳过独立教学不关闭这些提示。

| 时机 | 提示重点 |
| --- | --- |
| 首次部署 | 摆放单位与确认部署 |
| 首次增益选择 | 主帅增益的用途与选择 |
| 首次使用弓兵 | 相邻格盲区，以实际规则为准 |
| 首次使用炮 | 炮架及恰好一个间隔单位的攻击要求，以实际规则为准 |
| 首次获得可用 SP | 升级入口与作用，非阻断提示 |
| 首次涉及友伤 | 提醒可能伤及我方；不额外增加桌面攻击确认 |
| 首次遇到水 / 山 / 森林 | 分别在相关场景说明地形规则 |
| 首次出现增援预告 | 关注增援时间和位置 |
| 首次进入商店 / 替补席 | 购买与队伍管理 |

提示文案不得先于实际规则定稿；触发时机与频率为 TBD。

## 5. 状态、兼容与实现建议

- 教学地区使用独立标识 `tutorial`，与正式关卡 1–3 区分。
- 教学状态建议为 `unseen`、`completed`、`skipped`。只有实际达成教学目标才写入完成。
- 新玩家默认未学习；已有正式旅程不应被新增教学追溯阻断，仍可自行进入演武场。
- 完成 / 跳过状态与首次提示记录建议本地保存，开启新旅程不自动清除；存储不可用时退化为本次会话有效，不阻塞游戏。持久化范围待确认。
- 未完成教学退出后不保存步骤进度，再进入从头开始。
- 使用独立教学会话，保留并恢复原正式旅程状态；进入、退出、重学不改变正式旅程金币、队伍、关卡、战斗和成长。
- 复用已有规则、渲染与指令，按选中、移动成功、攻击、撤销和回合结算事件推进，避免依靠 DOM 文本匹配。
- 后续 UI 改造可能调整提示区与地图布局，本草案不锁定像素尺寸或最终视觉样式。
